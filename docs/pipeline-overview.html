3. Engine pipeline

Key settings (models.mjs)

  • Guided filter: radius 2, eps 1e-4, band radius 3.
  • Cleanup: minIslandFrac 0.0015, minIslandRel 0.02, maxPinholeFrac 0.00004.

  • Matting: ViTMatte, max side 768, lo 0.05, hi 0.95, trigger soft ratio 0.02.

7. Bike spokes analysis ◉ ANALYSED, NOT FIXED

Input bg-assets/bike.jpeg, 3000×2000. Output in bench-out/bike/.

MethodComponentsHolesSoft ratioVerdict
birefnet-legacy (raw)232570.0325already weak in wheels
birefnet-engine74540.04905–10 alpha points lower in wheels
birefnet-vitmatte9741300.0591noisy
modnet-engine14110.0274loses most of the bike
Causes Primary: model resolution
  1. BiRefNet input is a fixed 1024×1024 stretch (about 2.9× horizontal, 2× vertical downscale), so thin spokes shrink to about 1 px or less. The raw model alpha is already weak there.
  2. The engine's cleanup and guided filter lower the alpha further (inferred from the engine vs legacy difference, not isolated by an experiment).
  3. Crop refine did not run: bbox area ratio 0.698 is above 0.35.
  4. ViTMatte runs at 768 px max side and adds noise (974 components).
  5. MODNet is a portrait model.
Suggested changes (not implemented) ⏳ DEFERRED
  • Tiled or multi-scale BiRefNet inference at native resolution.
  • Protect thin structures in cleanup and limit alpha reduction by the guided filter.
  • Relax the crop-refine trigger beyond bbox area.
  • Tiled ViTMatte on the band, with component noise filtering.
  • Optional "thin structures" toggle; Restore brush as the manual workaround today.
  • Add bike to the regression set with a wheel-region alpha metric.

Not verified: the images were not viewed, and no engine change was tested. The ranking of causes is inferred from the numbers.
